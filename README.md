# NOXA Website

Official mobile-first launch website for NOXA.

## Stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS
- Motion for React
- Supabase (planned for waitlist persistence)
- Vercel (planned production hosting)

## Experience

The website is designed for mobile devices first, then expanded for tablet and desktop. The current implementation includes a scroll-linked Hero and a sticky Product Story covering Discover, Meet, Belong and Drive.

The current NOXA app splash screen is deliberately not used.

## Validation

GitHub Actions runs dependency installation, TypeScript validation, ESLint and a production Next.js build.
