# P0 acceptance notes

P0 is intentionally limited to information architecture, naming, navigation and homepage clarity.

Acceptance checks:

- Homepage primary promise is understandable without knowing NOXA beforehand.
- Working website features are visually separated from future app features.
- `Meets` always points to real public events.
- `Add Event` always points to the moderated submission path.
- `Organizer` always points to the authenticated organizer dashboard.
- `Communities` always points to the public community directory.
- Legacy `/radar` and `/radar/submit` remain compatible through redirects.
- No mobile-app repository or mobile-app Supabase changes.
