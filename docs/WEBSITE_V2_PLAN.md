# NOXA Website V2

Execution order is fixed: P0 → P1 → P2.

## P0 — Clarity

- `/meets` is the public NOXA Meets surface.
- `/radar` remains an internal/legacy route and redirects publicly to `/meets`.
- Homepage explains the product in seconds, not paragraphs.
- Main actions: Meets, Communities, Add Event, Organizer.
- Crews / Routes move out of primary website navigation until the app launches.
- Website-now and app-coming-soon are clearly separated.

## P1 — Event platform

- Individual public event pages.
- Shareable event URLs.
- Organizer event management view.
- Event analytics: views, shares, map clicks and referrer/source when technically reliable.
- No fake engagement metrics.

## P2 — Cinematic brand layer

- Strong hero media treatment with a lightweight fallback.
- One cinematic culture section.
- Restrained motion, image depth and transitions.
- Respect reduced-motion and mobile performance.
- No decorative HUD, fake maps, random neon lines or meaningless effects.

## Architecture boundary

Website and mobile app remain separate platforms until a later explicit synchronization project after app publication.
